## Déploiement GitHub Pages
1. Ouvrir **Settings → Pages** dans ce dépôt.
2. Dans **Build and deployment**, choisir **GitHub Actions** comme source.
3. Le workflow `.github/workflows/pages.yml` publie le contenu de la racine.
4. Vérifier l'état du workflow dans l'onglet **Actions**.
